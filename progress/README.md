# 进度记录

这个目录用于接续项目工作，保存当前状态和各次会话的进展，并链接已有实验材料。进度与结论进入 Git。实验原始数据保留在本地 `results/`，逐项工作决策保留在根目录 `decisions.tsv`，两者都被 Git 忽略。普通 clone 不包含这些原始材料，相关链接仅在持有本地实验目录时可用。

## 从这里开始

- [当前状态](current.md)记录现行设计、最新结果、未解决的问题和继续工作时的约束。
- [2026-10-08 会话记录](2026-10-08-research-skills.md)记录从技能构建到自主完成规则复测的过程，包含 session ID 和本机原始对话路径。该会话延续到 2026-10-09。
- [2026-10-09 其他 benchmark 记录](2026-10-09-other-benchmarks.md)记录五项小样本并行对比的范围、进展和报告。
- [2026-10-09 AI Idea 接入纠正与重跑](2026-10-09-ai-idea-rerun.md)记录通用 agent、官方任务与 adapter 的分工，以及新的评分预检。
- [实验说明](../docs/experiments.md)汇总各轮实验方法和结果。
- [2026-10-09 路由执行与仓库整理](2026-10-09-router-and-repository.md)记录当前入口变更、Git 保存范围与验证边界。
- 本地 `decisions.tsv` 保存逐项工作决策与证据，不随 clone 分发。

## 更新方式

完成有意义的阶段后更新 `current.md`，并在相应会话记录中补充变化、结果和证据链接。新会话建立独立记录，在这里添加链接。会话记录写清 session ID、日期和原始记录路径，方便回到当时的讨论。

把已完成的事实、当前解释和可能的下一步区分清楚。单题复测不能写成全量结果，运行成功不能写成任务已交付。候选回复、调用轨迹和评分以原始实验文件为准。

本机对话路径只保存为定位信息，不复制整个原始 transcript。不要在进度记录中保存凭据。
