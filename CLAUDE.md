# Experiment protocol

When running a controlled research-ideation experiment:

- Follow the task's assigned experimental condition.
- Use only knowledge and evidence allowed by the provided evidence package.
- Search the web only when the condition explicitly allows it.
- Treat the current research state as the source of truth.
- A primitive performs one cognitive transformation only.
- Use primitives only when permitted by the condition and routed or explicitly selected.
- Respect the task's token, tool, and primitive-call budgets.
- Return the final output in the task's benchmark schema.
